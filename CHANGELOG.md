## 0.1.0 (2026-08-19)

Initial public release: a Prettier plugin that formats Modelica source files using the [tree-sitter-modelica](https://github.com/OpenModelica/tree-sitter-modelica) grammar, with HTML annotations formatted via Prettier's built-in HTML formatter.
